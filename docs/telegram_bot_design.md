# تصميم بوت Telegram لـ Mkmoon

## النطاق

البوت قناة مراقبة وتنبيهات لنظام Mkmoon. يقرأ الحالة والقرارات والدورات والصفقات الورقية من نفس طبقة PostgreSQL وRedis، ولا يغير إعدادات النظام ولا يرسل أوامر إلى Binance.

## التشغيل

يعمل البوت داخل نفس Render Web Service عبر Telegram HTTPS webhook على `/telegram/webhook`. يرسل Telegram تحديثات `message` و`callback_query` فقط. يتحقق endpoint من ترويسة `X-Telegram-Bot-Api-Secret-Token`، ويتحقق من قائمة المستخدمين المسموح لهم قبل تنفيذ أي أمر. لا يستخدم `getUpdates` مع webhook.

## الأزرار الأساسية

| الزر | البيانات المعروضة |
|---|---|
| حالة النظام | حالة الخدمة وWorker وPostgreSQL وRedis ووضع Paper وآخر دورة |
| آخر دورة | الدورة المكتملة الأحدث، 25/25، القرارات، الأخطاء، الزمن، ومصدر البيانات |
| تشخيص 25 رمزًا | حالة كل رمز، Score التغطية، الاستراتيجية الأقرب، وأول شرط ناقص |
| لماذا لا توجد صفقة؟ | تجميع أسباب WATCH وNO_TRADE وسبب تكرار كل بوابة |
| الاستراتيجيات | اختيار استراتيجية ثم عرض الشروط المحققة والناقصة لكل رمز |
| القرارات الأخيرة | آخر القرارات مع status وreason codes وQuality Score عند وجوده |
| الصفقات الورقية | المراكز والأوامر الورقية المفتوحة والمغلقة والنتيجة المحققة |
| ملخص الأداء | عدد الدورات والرموز والأخطاء وPaper trades، دون ادعاء ربحية |
| السجل والتدقيق | أحداث آخر دورة والأخطاء مع Cycle ID |
| فتح Dashboard | رابط Dashboard الإنتاجية |
| المساعدة | شرح WATCH وNO_TRADE وScore التغطية وQuality Score وEV |

## الأمان

يُحفظ `TELEGRAM_BOT_TOKEN` في Render Environment فقط. يُحفظ رمز webhook السري في متغير Render مستقل مثل `TELEGRAM_WEBHOOK_SECRET`، ويُحفظ `TELEGRAM_ALLOWED_CHAT_IDS` كقائمة أرقام محادثات مسموحة. المستخدم غير المصرح له يحصل على رد عام ولا يستطيع قراءة بيانات التشغيل.

لا توجد أزرار شراء أو بيع أو تفعيل Live أو Force ENTER أو تغيير المخاطر أو تغيير الرموز أو حذف السجل. زر تحديث العرض يعيد قراءة البيانات المحفوظة فقط؛ ولا يبدأ دورة Worker جديدة ولا يتجاوز قفل Redis.

## حدود الرسائل

تُقسم القوائم الطويلة إلى رسائل قصيرة لا تتجاوز حد Telegram، وتُهَرب النصوص القادمة من السجل قبل إرسالها. لا يُرسل token أو connection URL أو أي سر إلى Telegram. تُترجم reason codes إلى العربية، وتبقى الأكواد الأصلية متاحة في تفاصيل التدقيق عند الحاجة.
